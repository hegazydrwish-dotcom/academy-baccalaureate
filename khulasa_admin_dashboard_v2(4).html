ملخص المنصة

الأرقام التالية تُقرأ من الجداول المعروفة في إعداد المشروع. ظهور شرطة يعني أن الجدول أو صلاحية القراءة تحتاج مراجعة.

الكورسات—academy_courses
الدروس—academy_lessons
طلبات الشراء—academy_purchases
المواد—academy_subjects
هذه نسخة تأسيسية مستقلة. لن يتم افتراض أعمدة أو إنشاء جداول جديدة أو تغيير بيانات قائمة قبل فحص مخطط قاعدة بيانات Supabase وسياسات الحماية RLS.

خريطة وظائف المنصة

إدارة العملية التعليمية

المراحل والصفوف والمواد والكورسات والدروس والملفات التعليمية.

إدارة المستخدمين

ملفات الطلاب والمعلمين، حالات الحسابات، وفريق الإدارة.

الاختبارات والتقييم

بنك الأسئلة، نماذج الامتحانات، التصحيح والنتائج.

الاشتراكات والتحصيل

طلبات الشراء، مراجعة الدفع، وتفعيل الاشتراكات.

التواصل

الإعلانات والتنبيهات ومواعيد البث وأرشيف المحاضرات.

المتابعة

التقارير والإحصائيات وسجل النشاط وإعدادات المنصة.

المراحل والصفوف الدراسية

إدارة المراحل من أولى إعدادي حتى ثالثة ثانوي، وإضافة الصفوف وربطها بالمواد والكورسات.

بانتظار مراجعة الجداول الحالية لمعرفة هل بيانات الصفوف محفوظة داخل academy_courses أو academy_subjects أم في جدول مستقل.

المواد الدراسية

إضافة المواد وتحديد المرحلة والصف وربط المادة بالمعلمين والكورسات.

سيتم تفعيل العرض والإضافة والتعديل بعد تأكيد أسماء الأعمدة والعلاقات في academy_subjects.

إدارة الكورسات

إضافة وتعديل الكورسات باستخدام الأعمدة التي تم التحقق منها في academy_courses.

رقماسم الكورسالصفالسعرالنشرإجراء
اضغط تحديث القائمة لعرض البيانات

إدارة الدروس والمحتوى

إضافة وتعديل الدروس وربطها بالكورس. رفع الملفات والفيديوهات سيُضاف بعد إعداد Storage.

رقمالكورسالدرسالترتيبمجانيإجراء
اضغط تحديث الدروس لعرض البيانات

مكتبة الملفات التعليمية

رفع ملفات PDF والملفات المساندة وتنظيمها حسب المرحلة والصف والمادة والكورس.

رفع الملفات يحتاج تحديد Storage Bucket وسياسات القراءة والتحميل. لن نضع ملفات الطلاب أو المحتوى المدفوع في مساحة عامة دون مراجعة الحماية.
واجهة تنظيم المكتبة جاهزة للتوصيل بعد فحص إعدادات Supabase Storage.

إدارة الطلاب

البحث عن الطالب، عرض بياناته وصفه، حالة الحساب، والكورسات المشترك بها.

نحتاج تحديد جدول ملف الطالب وربطه الآمن بحسابات Supabase Auth قبل عرض أو تعديل بيانات شخصية.

إدارة المعلمين

ملفات المعلمين، المواد المسندة إليهم، الكورسات والدروس والمحاضرات.

نحتاج فحص جدول ملفات المعلمين وعلاقته بحسابات المستخدمين قبل تفعيل الإدارة.

فريق الإدارة والصلاحيات

أدوار مقترحة: مدير عام، مساعد محتوى، مسؤول إعلانات، شؤون طلاب، متابعة.

سيتم فحص academy_staff وأدواره الحالية أولًا. لا يكفي إخفاء الأزرار؛ يجب فرض الصلاحيات في قاعدة البيانات أيضًا.

بنك الأسئلة

تصنيف الأسئلة حسب المادة والصف والدرس والوحدة ومستوى الصعوبة ونوع السؤال.

لا يوجد في الملفات المرسلة ما يثبت اسم جدول بنك الأسئلة أو بنيته؛ لن ننشئ بنية تخمينية قبل الاتفاق عليها.

الاختبارات والتصحيح الإلكتروني

إنشاء امتحانات، تحديد زمن ودرجة، اختيار الأسئلة، تصحيح الإجابات الموضوعية، وإظهار النتائج.

يحتاج هذا القسم إلى تصميم جداول الاختبارات والمحاولات والإجابات والنتائج، مع ضوابط تمنع كشف الإجابات قبل موعدها.

المشتريات والاشتراكات

عرض طلبات الشراء المسجلة. لا يتم اعتماد الدفع أو تفعيل اشتراك تلقائيًا من هذه الشاشة.

رقممعرف المستخدمالكورسالحالةالمبلغمرجع الدفعالتاريخ
اضغط تحديث الطلبات

الإعلانات والتنبيهات

نشر تنبيهات للطلاب والمعلمين وتحديد الجمهور ومدة ظهور الإعلان.

لم يتم التأكد من وجود جدول academy_announcements في قاعدة البيانات؛ سنربطه فقط بعد التحقق من وجوده وأعمدته.

البث المباشر وأرشيف المحاضرات

تحديد موعد المحاضرة والمادة والصف والمعلم ورابط البث والتسجيل، وتحديد الوصول المجاني أو للمشتركين.

يحتاج إلى جدول للمحاضرات وسياسة واضحة لحماية روابط المحتوى المسجل.

التقارير والمتابعة

تقارير التسجيلات، نشاط الطلاب، الكورسات، الدروس، المبيعات، الاشتراكات، ونتائج الاختبارات.

ستُبنى التقارير بعد توحيد مصادر البيانات والتحقق من العلاقات، حتى تكون الأرقام صحيحة وليست تقديرية.

إعدادات المنصة

اسم المنصة، الشعار، بيانات التواصل، إعدادات التسجيل، وسياسات المحتوى.

نحتاج تحديد هل توجد إعدادات محفوظة حاليًا أم سننشئ جدول إعدادات بعد مراجعة قاعدة البيانات.
